# 로봇용접 제조데이터 기반 불량위험 예측 및 안정 공정조건 분석

> **Predictive LSTM 기반 자기지도 이상탐지**
>
> 개별 생산기록의 정상/불량 라벨이 없는 제조데이터에서 공정 흐름을 학습하여  
> 생산기록별 이상 가능성을 식별하고, 주요 영향조건·모델 실패조건·저위험 안정 공정조건 후보범위를 도출한다.

---

## 1. 프로젝트 개요

로봇용접 공정에서는 가압력, 전류, 전압, 통전시간 등의 변화에 따라
미용접, 과용접, 기공, 균열 및 접합강도 부족 등의 품질문제가 발생할 수 있다.

본 프로젝트의 목표는 다음과 같다.

1. 최종 품질검사 이전에 생산기록별 **불량위험 이상을 탐지**
2. 이상탐지에 크게 영향을 준 **주요 용접조건 분석**
3. 모델이 불안정하게 판단할 수 있는 **실패조건 분석**
4. 이상탐지율이 상대적으로 낮은 **저위험 안정 공정조건 후보범위 제안**

제공 데이터에는 개별 생산기록 단위의 정상/불량 정답라벨이 존재하지 않고
날짜별 불량 집계정보만 제공된다.

따라서 제품 단위 이진분류 대신,
과거 공정 흐름을 학습하고 현재 공정값의 예측오차를 이상점수로 사용하는
**자기지도 기반 시계열 이상탐지 방식**으로 접근하였다.

최종 모델은 **Predictive LSTM**이다.

## 8. 데이터 특성 및 전처리

### 8.1 개별 생산기록 단위 불량라벨 부재

각 생산기록의 정상/불량 여부를 나타내는 정답라벨은 제공되지 않는다.

따라서 다음 지표는 직접 산출하지 않았다.

* Accuracy
* Precision
* Recall
* F1-score
* 제품 단위 False Positive
* 제품 단위 False Negative

대신 생산기록별 **이상점수**를 계산하고,
날짜별 **이상탐지 건수**와 제공된 실제 불량 집계건수의 차이를 평가하였다.

### 8.2 주요 전처리

* 주요 공정변수 결측치 확인
* 완전 중복 여부 확인
* 상수형 변수 제외
* 날짜·설비·품목·생산순번 기준 정렬
* 세부 시각이 없어 `idx`를 생산순서의 근사치로 활용
* `2020-03-27`은 `result` 집계가 없으므로 불량 0건이 아닌 **미확인**으로 처리
* Scaler는 학습구간에만 적합하여 데이터 누수 방지

|모델|방식|

|Local Outlier Factor|국소 밀도 기반 이상탐지|
|PCA|저차원 재구성 기반 이상탐지|
|KNN|거리 기반 이상탐지|
|LSTM AutoEncoder|시계열 복원 기반 이상탐지|
|Predictive LSTM|과거 공정기록 기반 현재 공정상태 예측|

> **평가 설계의 한계:** 후속 평가구간을 모델 간 최종 선택에도 활용했으므로,
> 이 구간의 성능은 완전히 독립적인 최종 테스트 성능이 아니다.
> 추가 미사용 기간의 데이터로 재검증이 필요하다.

## 11. Predictive LSTM 구조

Predictive LSTM은
과거 10개 생산기록의 공정변수를 이용해
현재 시점의 4개 공정변수를 예측한다.

```text
과거 10개 생산기록
        ↓
Predictive LSTM
        ↓
현재 공정값 예측
        ↓
실제값과 예측값의 차이
        ↓
이상점수 계산
        ↓
이상 판정 임계값 비교
        ↓
정상 / 이상 판정
```

주요 설정:

|항목|설정|
|-|-|
|Sequence length|10|
|Input features|4|
|Hidden dimension|32|
|LSTM layers|1|
|Dropout|0.2|
|Scaler|StandardScaler|
|Batch size|32|
|Learning rate|0.001|
|Early stopping patience|10|
|Score type|MAE|
|Random seed|42|

### 초기 시퀀스 구간

과거 10개 생산기록이 필요하므로,
각 날짜/생산그룹의 초기 10개 생산기록은 Predictive LSTM의 이상점수를 계산할 수 없다.

따라서 **11번째 생산기록부터 이상탐지가 가능하다.**

## 12. 이상점수와 이상 판정 임계값

### 12.1 이상점수

표준화된 실제 공정값과 Predictive LSTM 예측값 사이의
절대오차 평균을 이상점수로 사용한다.

```text
이상점수
= mean(|표준화 실제값 - 표준화 예측값|)
```

점수가 클수록
모델이 학습한 일반적인 공정흐름에서 더 크게 벗어난 상태로 해석한다.

### 12.2 이상 판정 임계값

학습구간에서 생성된 이상점수의 여러 분위수를 임계값 후보로 설정하고,
임계값 보정구간의 날짜별 이상탐지 건수와 실제 불량 집계건수의 차이가
가장 작아지는 값을 최종 임계값으로 선택한다.

```text
이상점수 >= 이상 판정 임계값
→ 이상으로 판정
```

## 13. 평가방법

제품 단위 정답라벨이 없기 때문에
날짜별 실제 불량건수와 이상탐지 건수의 차이를 평가한다.

```text
Daily MAE
=
mean(
    |날짜별 이상탐지 건수 - 날짜별 실제 불량건수|
)
```

후속 평가구간 결과:

|날짜|실제 불량건수|이상탐지 건수|차이|
|-|-:|-:|-:|
|2020-04-02|4|4|0|
|2020-04-03|4|4|0|
|2020-04-07|3|3|0|

```text
후속 평가구간 Daily MAE = 0.000 (모델 선정에도 활용한 구간)
```

> 날짜별 실제 불량건수와 이상탐지 건수가 동일하더라도  
> 동일한 개별 제품이 탐지되었다는 의미는 아니다.

## 14. 주요 영향요인 분석

이상으로 판정된 생산기록에서
각 공정변수의 절대 예측오차를 분해하여 기여도를 계산하였다.

```text
변수별 예측오차 기여도(%)
=
이상판정 기록에서 해당 변수의 절대 예측오차 합
/
이상판정 기록에서 전체 변수 절대 예측오차 합
× 100
```

분석 결과:

|변수|예측오차 기여도|
|-|-:|
|통전시간|**52.1%**|
|전압|**21.6%**|
|전류|13.6%|
|가압력|12.8%|

통전시간의 예측오차가
최종 이상점수에서 가장 큰 비중을 차지하였다.

> 해당 값은 실제 불량의 인과효과가 아니라  
> **모델의 이상판정에서 각 변수의 예측오차가 차지한 상대적 비중**이다.

## 15. 모델 실패조건 분석

개별 제품 단위 정답라벨이 없으므로
제품 단위 False Positive / False Negative를 직접 계산하지 않았다.

대신 다음 조건을 모델 실패 가능조건으로 분석하였다.

### 1) 과소탐지

```text
이상탐지 건수 < 실제 불량 집계건수
```

실제 불량 집계 대비 이상으로 식별된 기록이 부족한 상태이다.

### 2) 과대탐지

```text
이상탐지 건수 > 실제 불량 집계건수
```

필요 이상으로 많은 생산기록이 이상으로 판정될 수 있는 상태이다.

### 3) 임계값 직하위 기록

이상점수가 이상 판정 임계값 바로 아래에 위치하여
작은 공정변화에 따라 정상/이상 판정이 달라질 가능성이 높은 기록이다.

### 4) 초기 시퀀스 부족구간

각 생산일의 초기 10개 기록은 과거 시퀀스가 부족하여
Predictive LSTM 이상점수를 산출할 수 없다.

### 5) 변수 간 상호작용

단일 변수뿐 아니라 다음과 같은 복합 공정조건에서
이상탐지율이 높아지는지 분석하였다.

* 가압력 × 전압
* 전류 × 통전시간
* 전압 × 통전시간

## 16. 안정 공정조건 후보범위

### 16.1 산출 방법

```text
학습구간 + 임계값 보정구간의 이상점수 계산
        ↓
이상점수 하위 50%를 저위험 기록으로 정의
        ↓
저위험 기록에서 각 변수의 10~90% 범위 계산
        ↓
4개 변수 범위를 모두 만족하는 영역 정의
        ↓
후속 평가구간에서 범위 내부/외부 이상탐지율 비교
```

양 끝 10%를 제외한 이유는
극단값의 영향을 줄이고
저위험 데이터의 대표적인 중심구간을 사용하기 위함이다.

### 16.2 도출 결과

|공정변수|저위험 안정 공정조건 후보범위|
|-|-|
|가압력|**2.290 ~ 2.380 bar**|
|전류|**14.580 ~ 14.770 kA**|
|전압|**2.697 ~ 2.708 V**|
|통전시간|**71.000 ~ 72.160 ms**|

후속 평가구간에서의 이상탐지율:

```text
4개 조건 모두 충족 : 0.116%
1개 이상 범위 이탈 : 0.523%
```

후보범위를 하나 이상 이탈한 구간의 이상탐지율이
4개 범위를 모두 충족한 구간보다 약 **4.5배 높게** 나타났다.

> 본 범위는 실제 불량이 발생하지 않는 것을 보증하는 공정규격이 아니라,  
> 현재 데이터와 모델을 기준으로 산출한  
> **저위험 안정 공정조건 후보범위**이다.

## 17. 현장 활용방안

최종 모델은 실제 불량 여부를 확정하는 용도가 아니라
**품질검사 이전의 이상 가능 생산기록을 사전에 식별하는 보조수단**으로 활용한다.

```text
공정변수 입력
        ↓
Predictive LSTM
        ↓
이상점수 계산
        ↓
이상 판정 임계값 비교
        ↓
이상 가능 생산기록 식별
        ↓
우선 품질검사
        ↓
통전시간·전압 등 주요 영향변수 점검
        ↓
안정 공정조건 후보범위와 비교
```

활용 예시:

* 이상 가능 생산기록 우선검사
* 재검사 대상 선정
* 통전시간 및 전압 우선점검
* 안정 공정조건 후보범위 이탈 여부 확인
* 작업자의 공정조건 조정 의사결정 지원

## 22. 분석 한계

1. 제품 단위 정상/불량 라벨이 없어 개별 제품의 탐지 정확도를 직접 평가할 수 없다.
2. 날짜별 실제 불량건수와 이상탐지 건수가 같더라도 동일 제품을 탐지했다는 의미는 아니다.
3. 세부 시각정보가 없어 `idx`를 생산순서의 근사치로 사용한다.
4. 초기 10개 생산기록은 시퀀스 부족으로 Predictive LSTM 이상점수를 산출할 수 없다.
5. 안정 공정조건은 모델 기반 저위험 후보범위이며 실제 무불량 보증범위가 아니다.
6. 후속 평가구간을 최종 모델 선정에도 활용하여 독립적인 일반화 성능으로 해석할 수 없다.
7. 향후 개별 품질검사 라벨과 추가 공정센서가 확보되면 Precision, Recall, F1-score 및 원인분석을 고도화할 수 있다.
